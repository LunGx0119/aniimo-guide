# aniimo-guide

伊莫 Aniimo 繁體中文攻略圖鑑，包含圖鑑篩選、技能詳情、新手指引及配隊攻略。

原網站：https://aniimo-guide.lung-0119.chatgpt.site/

## GitHub Pages 發佈

在儲存庫 Settings → Pages，選擇 Deploy from a branch，分支 main、資料夾 / (root)，再按 Save。

本站為純 HTML、CSS、JavaScript，無需安裝套件或建置。更新 main 分支後，GitHub Pages 會重新發佈。

## 檔案

- index.html：頁面內容
- styles.css：樣式
- app.js：篩選、圖鑑詳情與互動
- aniimo-data.js：圖鑑資料
- .nojekyll：直接發佈靜態檔案

## 本機預覽

在本資料夾執行 `python -m http.server 8000`，瀏覽 http://localhost:8000 。
